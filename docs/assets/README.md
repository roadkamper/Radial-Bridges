# Project assets

Original radial logo and banner: MIT, like the application. They are not Bambu Lab logos.

- `banner.svg`: scalable README hero.
- `social-preview.png`: 1280 × 640 GitHub social card.
- `logo.svg` / `logo.png`: vector and 512 × 512 raster project mark.
- `app-preview.png`: actual Qt application screenshot on synthetic test G-code.
- `fine-tuning.png`: actual fine-tuning controls with the same synthetic preview.

Screenshots are rendered on Linux with offscreen Qt. They are not photographs of a printed part, proof of Windows execution, or a printer simulation. Windows app and installer icons use the new radial logo, converted to a multi-resolution ICO.
