# Security and printer safety

Do not print untrusted G-code. The app parses and rewrites selected paths; it is not a sandbox, malware scanner, or printer safety verifier.

For security-sensitive bugs, contact the repository owner privately using an available GitHub private-report channel. Before public launch, enable GitHub private vulnerability reporting; no private contact address is invented here. If unavailable, open an issue asking for a private contact without including exploit details or sensitive files.

Include the affected version, a minimal synthetic reproduction, and the expected state. Report incorrect extrusion or command relocation as safety bugs. No security-support SLA is promised.
